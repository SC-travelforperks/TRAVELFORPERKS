
## Travel For Perks

Luxury travel advisor site built with Next.js 15, TypeScript, and Tailwind CSS.

### Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

### Production

This project is ready to deploy on Vercel as a standard Next.js application.

### Current content model

The following sections are currently hardcoded and structured so they can later be swapped to a CMS such as Notion:

- Deals
- Gallery
- Blogs
